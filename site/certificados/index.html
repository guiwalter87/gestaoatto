Validação de certificados.

Confira a autenticidade de um certificado de programa ou treinamento emitido pela Atto. Escaneie o QR Code impresso no certificado ou digite o código de validação abaixo.

Como funciona

Cada certificado tem um código único.

O código aparece no verso do certificado, logo abaixo do QR Code. A consulta confirma se o documento foi emitido pela Atto e se continua válido.

  • 01Escaneie o QR Code com a câmera do celular, ou digite o código no campo ao lado.
  • 02O resultado mostra titular, programa, período, carga horária e data de emissão.
  • 03Os dados só são exibidos para quem tem o código. Não existe listagem pública de participantes.

Consultar certificado

Informe o código exatamente como aparece no certificado. Letras maiúsculas ou minúsculas são aceitas.
